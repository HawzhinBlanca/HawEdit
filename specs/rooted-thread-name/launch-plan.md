## Fixed Lifecycle

1. Dedicated Linux creator uses existing sealed Bootstrap and original parent
   death binding. Establish original unnamed owner/result channels, fixed null
   creator stdio, and bounded Windows native lifetime where applicable.
2. Trusted private PID1 creates exactly original PID2, held before any image
   preparation or SDK code. Actual Scope challenge/credentials/EOF/pidfds admit
   both original processes in the original namespace. No model release on G:
   G only lets this trusted preparation continue. Parent retains cancellation.
3. Default-off typed RootedCommand declaration contains only a manifest-listed
   executable, bounded argv and explicit bounded environment. No callable,
   shell string, web path, generic FD allowlist or public unfenced object.
   Snapshot validates its exact launch capabilities before accepting exceptions
   to its outside-description inventory; only original worker/control handles.
4. Preserve Snapshot's exact initial capability boundary and _initialize order.
   Copy/hash/size-check complete declared bytes in owned tmpfs; no new install,
   source-backed data, writable scratch or model substitution. Prepare proc and
   fixed entropy/GPU endpoints; seal readonly root/proc before worker access.
5. Trusted single-thread PID2 receives only original private user/mount/root
   handles over its original channel. Check kernel namespace types, direct
   descendant/owner relationships, mount-owner binding, original descriptions,
   sealed root identity and current original PID1/PID2 lineage. The outside owner
   re-observes the prepared view through original pidfds before release. A typed
   kernel-derived transition proof is required; no caller True/receipt grant.
   Generic Scope checks/EOF are not loosened or treated as this new proof.
6. PID2 joins only those exact private user then mount namespaces, enters only
   the sealed original root, closes every outside/bootstrap handle and drops all
   effective/permitted/inheritable/bounding/ambient caps. Verify NNP/root/proc/
   fixed leaf identities. Mandatory worker Landlock before copied exec/import.
   Install exact notification listener as part of shared fence generation before
   stronger errno rules; never stack it after an existing stronger denial.
7. Trusted TRACEME/start stop, original registry anchoring, restricted clone/exec
   observation, original listener handoff and bounded source broker precede SDK
   release. Worker cannot join namespaces, ptrace, fork process groups, obtain
   foreign handles, or write proc/root/scratch. Fixed private result channels
   only; no general file broker. Reuse shared policy implementation, not a second
   Snapshot or pipeline. Parent controller keeps only narrow original capability
   and restricted syscalls while servicing; no SDK import in controller.
8. Typed launch does not return while any member/IO/timer/billing is uncertain.
   Original pidfd cancellation/all-member drain, listener/result limits and
   original Scope lifetime are mandatory. Before Snapshot constructor can return,
   controller also gets its normal final Landlock/seccomp/inspect contract.
   Default constructor path and refusals remain unchanged. Diagnostic ceiling:
   30s execution,64births/32requests/64KiB evidence, existing finite preparation
   bounds; no silent extension to full-model/episode runtime.
