# Specification — current acceptance records

1. WHEN an operator reads the WSL-ASR setup section, THE documentation SHALL state that the
   protected exact-main VEX job has succeeded and SHALL preserve its expiry and affected-risk
   limitations.
2. WHEN an operator provisions the measured Windows GPU environment, THE documentation SHALL point
   to the packaged hash-locked GPU profile and runtime verifier rather than an obsolete unlocked
   bootstrap.
3. WHEN M3.7 summarizes release readiness, THE ledger SHALL distinguish the completed live OIDC
   attestation from the still-absent human-authorized version tag and durable public release.
4. WHEN the audit describes OmniASR integrity, THE report SHALL describe exact card/asset byte
   binding and SHALL name native KenLM/Sox build outputs as the remaining reproducibility boundary.
5. WHEN the audit describes real ASR execution, THE report SHALL acknowledge the dated 38-minute
   Sorani run while refusing to treat it as current-SHA or labelled-accuracy proof.
6. WHEN new measurements are recorded, THE evidence SHALL include exact source SHA, run IDs,
   artifact digests, wheel hashes, Python versions and explicit non-claims.
