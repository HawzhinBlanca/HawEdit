## Methodological Boundary

Within-cluster dependence can substantially understate uncertainty when treated as
independence. Multiway grouping and few-cluster behavior require distinct treatment;
simply clustering on the intersection does not preserve both dependency dimensions.
[Cameron and Miller, 2015, sections V-VI](https://cameron.econ.ucdavis.edu/research/Cameron_Miller_JHR_2015.pdf).
Inference for HawEdit must explicitly define episode and repeated-reviewer populations;
this is a design inference from the paper, not automatic validation of any chosen model.

SciPy's paired bootstrap preserves corresponding array indices. That option alone does
not select episode/reviewer blocks; whole-row resampling would leave our dependency
problem unresolved. [SciPy bootstrap documentation](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html).
No package is installed or statistical dependency approved here. Preregister the estimand,
weighting, ties/refusals/no-clip episodes, dependency model, finite-cluster correction,
coverage/reference validation and fixed decision rules before holdout observations.
