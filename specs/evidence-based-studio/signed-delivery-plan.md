## Proposed Protocol

Prepare a version-1 canonical review envelope under owner-private storage. Bind candidate/
revision and source identity, producer/package identity, authoritative resolved configuration,
the six D-263 delivery files and edit plan, with exact sizes and SHA256s. Include validated
human review assertions but label them as authenticated assertions, not measured facts.
Use strict duplicate-key/schema/type/time validation and bounded files/streams.

Freeze the final publication editing JSON, including the proposed QC metadata, before the
reviewer signs. Bind both the prior plan identity and this exact final JSON. After approval,
copy it unchanged; do not sign old bytes and inject Qc afterward. Burned-in revisions remain
new immutable renders with new hashes and invalidated approvals, a separate mandatory unit.

Verify real detached OpenSSH proof in a dedicated hawedit-candidate-review namespace, using
owner-configured trusted principals/keys, bounded subprocesses and stable private snapshots.
Web requests cannot supply their own allowed-signers policy or grant trust. Preserve existing
release/editorial namespaces. No verified=True result object may authorize publication alone:
reopen raw proof, artifacts and configured authority at consumption.

Stage a versioned exact publication set containing unchanged reviewed media/sidecars/plan
plus canonical review envelope and detached proof. Retain the existing legacy seven-file
packaging contract for private candidates/diagnostics; it must not represent verified public
delivery. Add only the shared bundle behavior required for the proof-bearing variant, not a
broad pipeline rewrite or arbitrary extra-file escape hatch. Record this QC extension as a
proposed D-277 ADR before adoption; do not silently change frozen BLUEPRINT.

Freshly inspect/decode and measure a bound candidate snapshot with the recorded toolchain,
then reconcile against the authenticated plan/configuration and evidence. Saved measurement
JSON is not measured truth by itself. Stream large sources; bound storage, subprocess time
and file identity. Fail closed on incomplete or changing artifacts. Preserve actual measured
policy failures; face presence does not become speaker identity.
