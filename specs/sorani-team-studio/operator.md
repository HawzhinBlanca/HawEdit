# Running the Sorani podcast Studio

From the HawEdit checkout in PowerShell, run `./.venv/Scripts/python.exe -m hawedit.web` and open `http://127.0.0.1:8080` on the same computer.

In Studio, paste a YouTube episode URL or upload the source, then choose the V8 engine. Enter the guest name for this episode. Select Arabic or English subtitles or stock dubbing if needed. The local director uses offline stock by default. Gemini requires a new decision for each Studio job.

In the local Studio, open a completed clip’s selection evidence to read each quoted passage with its original episode time. Select a source word, enter the corrected spelling, save it, and generate again from the same upload. The next job records the edits and preserves word timing. Restoring the original spelling removes that edit. Earlier renders and ASR records stay available.

The episode CLI accepts the same YouTube URL or a file. For example, run `python -m hawedit.v8 episode URL --source-library LIBRARY --transcript WORDS.json --out-dir OUTPUT`. Aligned transcripts and the source video must share the same clock. The optional `--subtitles en --dub ar` creates an English subtitle draft and an Arabic dubbed variant. The host reads non-secret settings from `media-tools.json` next to the HawEdit user credential file. Supported keys are `youtube_library`, `translation_model`, `voice_python`, and `voice_weights`. HAWEDIT-prefixed environment variables override the corresponding keys.

Open `blind-review.html` for offline native-speaker scoring. The client gallery links each social package. Team mode uses the finished episode manifest, copies accepted packages into private snapshots, and binds approvals and ballots to the exact ZIP bytes. Create a member locally with `python -m hawedit.v8 team --state STATE invite NAME`. Add `--approver` for editorial approval authority. The command displays the member password once. Serve with `python -m hawedit.v8 team --state STATE serve OUTPUT`. For phones on a private network, specify the private IPv4 interface with `--bind`, a trusted server certificate with `--tls-cert`, and its key with `--tls-key`. An approved member can download a posting pack from a phone. Putting the pack on hold closes future downloads.

For a standalone local translation, run `python -m hawedit.v8 localize CLIP.v8.srt --language en --language ar --model MODEL`. The Studio translation server listens at 127.0.0.1:1234/v1. A native editor should review the resulting drafts. Dubbing takes the translated subtitle timing and preserves the source audio as an alternate track. Run `python -m hawedit.v8 dub REEL.mp4 TRANSLATION.srt --language en --voice-python WORKER --weights MODEL_DIRECTORY`. The isolated worker uses chatterbox-tts 0.1.7, its Perth watermark, and the ResembleAI/chatterbox multilingual weights. The verified Windows installation uses setuptools 80.10.2 for Perth's pkg_resources dependency.

Stock voice is the default. A cloned voice additionally requires `--reference REFERENCE.wav --consent GRANT.json`. A producer must verify the speaker's actual consent evidence. The record contains `scope` equal to `podcast-dub`, `speaker`, `confirmed_by`, `languages`, an ISO 8601 `expires_at` with timezone, `reference_sha256`, `reel_sha256`, `evidence_file` relative to the grant, and `evidence_sha256`. Keep the grant, evidence and voice sample private. None belongs in the social ZIP.

For TikTok or Instagram manual posting, download the approved package on the phone. For direct Instagram publishing, the operator must connect an eligible professional account through Facebook Login for Business and provide its Meta token via `HAWEDIT_META_ACCESS_TOKEN`. Explicitly run `python -m hawedit.v8 publish-instagram PACKAGE --state STATE --account INSTAGRAM_ID`. The publisher uploads the approved reel directly to Meta, checks processing, and records the media ID. Repeating the command uses the stored container. After an ambiguous publish response it checks the existing container and avoids submitting another publication.

In automatic mode the local director compares complete, measured source excerpts. It scores each for opening, payoff, context and specificity, then refines the selected edits. Explicit `--story-mode semantic-multicut` instead asks the director to nominate its own word spans in overlapping transcript sections. Repeating the episode command with the same output directory can reuse completed nominations from `.work/story-nominations`. Changes to source words, timing, model or prompts produce new cache entries. The refiner and meaning check still run on the selected candidates.
