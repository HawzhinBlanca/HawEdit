## 1. Goal
Ensure that dynamic punch-in zooms generated by `crop_filter` keep the subject's face anchored on the 0.38 composition line rather than dropping the face down to 0.50 (dead center).

---

## 2. Changes

### 2.1 `src/hawedit/render.py`
In `crop_filter`:
When `face_center_y is not None`:
```python
y_expr = f"min(max({face_center_y}-{FACE_COMPOSITION_LINE}*out_h\\,0)\\,in_h-out_h)"
```
When `face_center_y is None`:
```python
centre_y = source_height // 2
y_expr = f"min(max({centre_y}-out_w/2\\,0)\\,in_h-out_h)"
```

### 2.2 `tests/test_render.py`

- Assert that `y_expr` contains `400-0.38*out_h`.
- Verify behavior when `face_center_y=None` retains `out_h/2`.
