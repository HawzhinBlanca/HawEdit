## Existing decisions to preserve or explicitly revise

D-265 governs content presets; D-266 governs trimming; D-269/D-270 govern caption treatment; D-271 governs independent visual discovery. Changing a mandatory existing audio policy still needs the normal ADR rather than an incidental code deletion.
